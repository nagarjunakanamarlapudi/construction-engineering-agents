# Civil Engineering Project Copilot End-to-End Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a reproducible academic Civil Engineering Project Copilot that demonstrates direct RAG, hybrid retrieval and reranking, Graph RAG, routed and agentic investigation, cited answers, memory, evaluations, notebooks, and a trace-visible chat UI.

**Architecture:** PostgreSQL owns authoritative structured records, Qdrant owns document vectors and retrieval metadata, Neo4j owns project dependency paths, and managed Mem0 owns approved preferences only. Python services expose the same domain and retrieval interfaces to the FastAPI API, LangGraph workflow, Streamlit UI, evaluation runner, and Jupyter notebooks.

**Tech Stack:** Python 3.12, uv, Pydantic, FastAPI, Streamlit, LangChain, LangGraph, PostgreSQL, Qdrant, Neo4j Community, Mem0 Platform, OpenAI, Langfuse Cloud, Docker Compose, pytest, Ruff, Bandit, pip-audit.

**Spec:** `PROPOSAL.md`

## Global Constraints

- All public and synthetic records retain origin, source path/URL, revision or effective date, and citation coordinates where available.
- Synthetic records use one internally consistent India-based structural-steel project and are visibly labelled `SYNTHETIC — ACADEMIC DEMO`.
- BIS preview/catalogue material is never described as the complete text of an Indian Standard unless verified.
- Agents and memory never query databases directly; typed read-only tools enforce project and access filters.
- The UI shows route, plan summary, tool calls, observations, evidence, citations, and evaluation scores—not private chain-of-thought.
- `.env` remains ignored; no secret enters source control, images, notebooks, logs, or test fixtures.
- Every production behavior is introduced with a failing test and verified green before the next task.
- Proposal statuses and architecture images change only after the corresponding health check or test passes.
