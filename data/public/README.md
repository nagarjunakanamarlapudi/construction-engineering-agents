# Public Seed Data

This directory contains public technical material acquired for academic research and testing. Every retained dataset records its publisher, source URL, retrieval date, checksum, access type, intended use, and limitations.

## Contents

- `buildingsmart/ifc-pcert/`: four unmodified IFC4 discipline files from buildingSMART Certification Datasets, licensed CC BY 4.0.
- `buildingsmart/bcf-test-cases/`: one unmodified BCF 3.0 conformance test archive from buildingSMART BCF-XML, licensed CC BY-ND 4.0.
- `bis/academic/`: official public BIS catalogue and preview pages plus a labelled, portable text corpus for 28 India building/structural standard families. See its [dataset README](bis/academic/README.md).
- `MANIFEST.csv`: source, retrieval date, size, checksum, licence and intended use for each retained artifact.

These files are technical and academic research inputs. They are not one Indian building project, do not establish compliance with Indian standards, and are not substitutes for authorized project records.

The broader link-only source assessment is in [Public Data Catalogue](../../docs/PUBLIC_DATA_CATALOG.md).
